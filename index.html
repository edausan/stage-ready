🥁 Kick Drum

EQ

  • HPF: 30–40 Hz
  • +4 dB @ 60–80 Hz (thump)
  • −4 dB @ 250–400 Hz (mud)
  • +3 dB @ 3–5 kHz (attack)

Compressor

  • Ratio: 4:1
  • Attack: 20–30 ms
  • Release: 60–120 ms
  • GR: 4–6 dB

Notes

  • FOH: emphasize punch
  • IEM: reduce sub if muddy

🎸 Bass

EQ

  • HPF: 40–50 Hz
  • +3 dB @ 80–120 Hz
  • −4 dB @ 250–350 Hz
  • +2 dB @ 700 Hz–1 kHz

Compressor

  • Ratio: 4–6:1
  • Attack: 20–40 ms
  • Release: 100–200 ms
  • GR: 5–8 dB

Notes

  • Consistency over loudness
  • Critical for IEM clarity

🎸 Electric Guitar

EQ

  • HPF: 80–120 Hz
  • −3 dB @ 200–300 Hz
  • +2 dB @ 2–4 kHz

Compressor

  • Ratio: 2–3:1
  • Attack: 30 ms
  • Release: 120 ms
  • GR: 2–4 dB

Notes

  • Let amp do the tone
  • EQ = cleanup only

🎤 Vocals

EQ

  • HPF: 100–120 Hz
  • −4 dB @ 250–350 Hz
  • +3 dB @ 4–6 kHz
  • +2 dB @ 10–12 kHz

Compressor

  • Ratio: 3:1
  • Attack: 5–10 ms
  • Release: 60–100 ms
  • GR: 4–6 dB

Notes

  • Clarity > volume
  • Always check IEM fatigue
